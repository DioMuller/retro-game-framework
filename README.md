# Retro Game Framework

This is a simple framework created with the objective to study older game platforms, their architectures and limitations. 

The initial idea is to create a both a project/scripts that install many platforms toolsets and emulators, and to create base calls for all platforms that allow for the same game to be compiled for as many consoles as possible with only assets and some eventual code unique to each platform.

## Supported Platforms

Currently, the initial plan is that the first version will support the following platforms:

* Game Boy
* Game Boy Color
